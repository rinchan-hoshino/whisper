# 纸条 2.0 实机核对表

在 Windows 上用打包好的 OopzTacticalOverlay.exe 按顺序执行。每步记录结果：通过、失败（附现象）或跳过（附原因）。

1. 启动：Oopz 未开时，浮层显示「先打开 Oopz 并登录」，每 5 秒自动重试，托盘出现图标。
2. 连接：打开并登录 Oopz，进入语音频道后，左下角绿点亮起，浮层显示该语音服务器的文字频道消息。
3. 收消息：别人发一条消息，浮层出现一行「昵称：内容」，约 10 秒后淡出；提示音响一声；自己发的不响。
4. 提示音：设置里关闭提示音后收消息不响；调到 0 音量也不响；调回后恢复。
5. 输入：游戏窗口在前台，按 F8，输入中文并按 Enter，消息出现在 Oopz 频道里，输入框清空，焦点回到游戏。
6. 取消：按 F8 输入一半，按 Esc，草稿保留；再按 F8 草稿还在，焦点回到游戏。
7. 显示切换：按 F9 浮层隐藏，再按 F9 显示；游戏里鼠标点击穿过浮层，不抢焦点。
8. 断网重连：断开网络 30 秒后恢复，绿点变红再变绿，期间的消息补上；不出现重复消息。
9. 旧版设置迁移：在装有 1.x 的机器上直接启动 2.0，原频道、热键、字号保留。
10. 更新替换：把清单指向一个新版本（测试环境），旧版下载后重启，替换成新版，浮层显示「纸条已更新到 x.y.z」，设置保持不变。

验收后清理测试进程和临时文件，确认退出后热键释放（F8、F9 在其他程序里可用）。
